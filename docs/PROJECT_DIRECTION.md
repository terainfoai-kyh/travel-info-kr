## 🎯 3. 세부 단계별 구현 로드맵 (Actionable Milestones)

### 📌 Phase 1. 첫 화면 랜딩 UX 고도화 (마이플랜US 장점 흡수)
- [x] **16:9 모던 시네마틱 보상 광고 모달 적용** (완료)
- [x] **100/100 한국 대표 명소 로컬 정품 사진 에셋화** (완료)
- [ ] **빠른 여행 퀵 필터 칩 (Quick Intent Chips)**:
  - `"인천공항 출발 2박 3일"`, `"서울 K-컬처 & 성수 핫플"`, `"KTX 부산 1박 2일"` 등 원클릭 시작 칩 강화.

### 📌 Phase 2. 대화형 AI 일정 생성 및 실시간 재계산 강화
- [ ] **상황별 실시간 여행 코디네이팅 (Dynamic Context Adjustment)**:
  - 예: `"지금 비 오는데 실내 코스로 바꿔줘"`, `"부모님 모시고 가니까 덜 걷는 코스로"`, `"예산 10만원 아끼는 코스로"` 입력 시 즉시 일정 및 동선 재배열.
- [ ] **하버사인(Haversine) 기반 0원 GPS 동선 최적화**:
  - 외부 유료 길찾기 API 없이도, 브라우저 단에서 여행지 간 최적 이동 순서 자동 정렬.

### 📌 Phase 3. 외국인 여행자 필수 인프라 가이드 연동 (Foreigner-First)
- [ ] **외국인 필수 7대 실용 정보 즉시 답변 카드**:
  1. 🚇 **지하철 / 버스 / 티머니 / 기후동행카드 가이드**
  2. 💳 **해외 카드(비자/마스터) 결제 & 와우패스(WOWPASS) 안내**
  3. 📱 **eSIM / USIM 공항 수령 및 활성화 방법**
  4. 🚕 **카카오T / 우버(Uber) 외국인 탑승 팁**
  5. 🚆 **코레일(KTX) 영문 예약 & 짐 보관(Luggage Lockers) 위치**
  6. 🍜 **식당 주문 / 알레르기 카드 / 비건(Vegan) 안내**
  7. 🚨 **외국인 전용 24시간 관광통역 안내전화(1330) 원클릭 연결**

### 📌 Phase 4. 커머스 제휴 및 지속 가능한 수익화 (Monetization Funnel)
- [ ] **스마트 제휴 카드 (Affiliate Deep-link Context Cards)**:
  - AI가 경복궁/남산 일정을 짤 때 ➔ **'디스커버 서울패스' 클룩 제휴 링크** 노출
  - AI가 부산/강릉 일정을 짤 때 ➔ **'아고다 호텔 최저가 & KTX 코레일패스' 제휴 링크** 노출
- [ ] **3단계 멤버십 리워드 시스템 최적화**:
  - 무료 기본 5회 ➔ 15초 보상형 시청(+3회 충전) ➔ Google 로그인 매일 15회 VIP 혜택.

### 📌 Phase 5. 비용 0원 & 초고속 데이터 아키텍처 유지
- [ ] **자율 적재형 스마트 시맨틱 캐시 (Semantic Cache Engine)**:
  - 자주 묻는 한국 여행 질문(서울 3박4일, 부산 2박3일 등) 응답을 로컬/KV에 캐싱하여 API 비용 0원 & 0.05초 로딩 실현.
- [ ] **3중 API 장애 방어막 (Safety Net)**:
  - 공공 API나 LLM 장애 시 로컬 마스터 데이터베이스로 0.1초 자동 롤백되어 서비스 무중단 보장.

## 💡 5. 개발 원칙 및 운영 수칙 (Core Rules)
1. **절대 기존 여행사처럼 무거운 쇼핑몰 구조를 만들지 않는다.**
2. **모든 새로운 기능은 글로벌 외국인 기준(다국어, 직관적 UI)으로 최우선 검증한다.**
3. **개발-운영 배포 이원화(Two-Track Deployment)를 철저히 준수한다.**
